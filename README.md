# Dosis Perronas — React (Vite)

Proyecto migrado a React + Vite con la funcionalidad original preservada.

Pasos rápidos para ejecutar:

1. Instala dependencias:

```bash
cd /workspaces/codespaces-blank
npm install
```

2. Levanta el servidor de desarrollo:

```bash
npm run dev
```

El proyecto usa Tailwind vía CDN en `index.html` para mantener estilos tal como estaban.

Siguientes pasos recomendados:
- Añadir `react-router` y separar las vistas en rutas (task pendiente).
- Añadir configuración de Tailwind local si se desea rendimiento y personalización.
